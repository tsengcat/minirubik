## 2. 量測一：每個 guest byte 佔多少 host 記憶體

### 方法

- 控制組 `empty.s` 只做 `li a7, 10` 加 `ecall`。
- `full_*.s` 從 `buf`（`0x10000000`）開始，用 `sw` 連續寫入 N bytes。
- 每次執行都用 `/usr/bin/time -l`，記錄 `maximum resident set size`（RSS）和 `peak memory footprint`（FP）。
- 比值為 (B − A) / N。斜率是 N = 512,000 和 1,024,000 兩點之間的差值斜率。
- 用 `--iret` 驗算寫入量：預測值 = 3 × (N/4) + 8，實測全部相符。

```sh
/usr/bin/time -l ./Ripes-v2.2.6-106-g5b8a616-mac-universal2.app/Contents/MacOS/Ripes \
  --mode cli --src asm/test_mem/<file>.s -t asm --proc RV32_ISS --iret
```

| 程式 | N（bytes） | iret |
| :--- | ---: | ---: |
| `asm/test_mem/empty.s` | 0 | 2 |
| `asm/test_mem/full_512KB.s` | 512,000 | 384,008 |
| `asm/test_mem/full_1024KB.s` | 1,024,000 | 768,008 |
| `asm/test_mem/full_256KB.s` | 2,560,000（**檔名不符，不採用**） | 1,920,008 |

`swaps` 全部是 0。N = 2,560,000 這組因檔名與內容不符，不列入計算。

## 3. 量測二：每秒執行幾條指令

### 方法

- `mem_loop_<COUNT>.s`：迴圈內容是 `sw t1, 0(t0)`、`addi t1, t1, -1`、`bne t1, x0, loop`。每圈 3 條指令，一直寫同一個位址。
- `reg_loop_<COUNT>.s`：迴圈內容是 `addi t0, t0, -1`、`bne t0, x0, loop`。每圈 2 條指令，不存取記憶體。
- 時間取 `--exectime`（ms）。
- 速度 = (iret大 − iret小) / (t大 − t小) × 1000，用來扣掉固定開銷。每組時間取中位數。
- iret 實測值全部符合預測：
  - mem：3 × COUNT + 5（COUNT ≤ 2047）或 + 6（更大）
  - reg：2 × COUNT + 3 或 + 4
  - 多出來的 1 條，是 `li` 的立即值超過 12 位元、要多一條 `lui`。

```sh
./Ripes-v2.2.6-106-g5b8a616-mac-universal2.app/Contents/MacOS/Ripes \
  --mode cli --src asm/test_rate/<file>.s -t asm --proc <MODEL> --iret --exectime [--timeout 600000]
```

### 原始數據：`RV32_ISS`

| COUNT | mem iret | mem exectime（ms） | reg iret | reg exectime（ms） |
| ---: | ---: | :--- | ---: | :--- |
| 1 | 8 | 37 / 38 | 5 | 42 / 38 |
| 100 | 305 | 42 / 38 | 203 | 42 / 47 |
| 10,000 | 30,006 | 39 / 38 | 20,004 | 45 / 42 |
| 1,000,000 | 3,000,006 | 169 / 170 | 2,000,004 | 93 / 96 |
| 100,000,000 | 300,000,006 | 16,682 / 16,652（另有 1 次手動 Ctrl-C 中斷，不計） | 200,000,004 | 7,695 / 8,781 / 8,507 / 9,108 / 7,343 |

### 原始數據：`RV32_5S`（mem_loop）

| COUNT | iret | exectime（ms） |
| ---: | ---: | :--- |
| 10,000 | 30,006 | 67 / 67 |
| 1,000,000 | 3,000,006 | 6,534 / 6,621 |

### 計算結果

| 模型與迴圈 | 用哪兩組 | 速度（條/秒） | 10⁹ 條需時 | 5×10⁷ 條需時 |
| :--- | :--- | ---: | ---: | ---: |
| `RV32_ISS` mem | COUNT 1 → 10⁸ | **18.04 M** | 55.4 秒 | 2.8 秒 |
| `RV32_ISS` reg（中位數 8,507 ms） | COUNT 1 → 10⁸ | 23.62 M | 42.3 秒 | 2.1 秒 |
| `RV32_ISS` reg（最小值 7,343 ms） | COUNT 1 → 10⁸ | 27.38 M | 36.5 秒 | 1.8 秒 |
| `RV32_5S` mem | COUNT 10⁴ → 10⁶ | **456.2 K** | 36.5 分鐘 | 1.8 分鐘 |

與作業表格比較（作業表格用的是記憶體迴圈）：

| 模型 | 作業表格 | 本次量測 | 倍數 |
| :--- | ---: | ---: | ---: |
| `RV32_ISS` | 1.09 M/秒 | 18.04 M/秒 | 16.6 倍 |
| `RV32_5S` | 20.5 K/秒 | 456.2 K/秒 | 22.3 倍 |

本機上 `RV32_ISS` 比 `RV32_5S` 快 39.5 倍。

### 補充：`RV32_ISS` 上一個 `sw` 的模擬成本

- mem 迴圈每圈 166.3 ns，reg 迴圈每圈 84.7 ns（中位數），兩者只差一條 `sw`。
- 一條 `sw` 約 81.6 ns，一條暫存器指令約 42.3 ns，相差約 1.9 倍。
- 這只影響模擬所需的時間。評分用的 `--iret` 對每條指令都算 1。

## 4. 注意事項與待辦

1. **電源狀態。** 所有測試都在同一環境下進行：電池供電、低耗電模式開啟。目標是環境穩定一致，不追求最佳效能，因此不重跑。
2. **reg 迴圈波動大。** COUNT 10⁸ 的 5 次結果在 7,343 ~ 9,108 ms 之間，相差 24%。mem 迴圈只差 0.2%，5S 只差 1.3%。
3. **一次手動中斷。** `RV32_ISS` mem COUNT 10⁸ 有一次是手動按 Ctrl-C 中斷，不列入計算。
4. **短程式算出的速度偏快。**
   - ISS mem：COUNT 1 → 10⁶ 是 22.7 M/秒，10⁶ → 10⁸ 是 18.0 M/秒。
   - ISS reg：分別是 36.7 M/秒和 24.3 M/秒。
   - 原因未查明，以上計算一律使用最大的 COUNT。
5. **固定開銷。** `--exectime` 在 ISS 上約 38 ms，COUNT 1 ~ 10,000 的時間幾乎相同。
6. **檔名不符。** `full_256KB.s` 實際寫入 2,560,000 bytes，這組數據不採用；`full_1024KB.s` 是 1,024,000 bytes（1000 KiB，不是 1 MiB）。
7. **已 commit。** `asm/` 底下的量測程式已在 `d46276a` commit 並 push。
